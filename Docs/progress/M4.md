### M4.1 notes (proximity voice)
- Seam (Abandoned.Voice): `IVoiceCapture` (mic -> encoded packets) + `IVoiceCodec` (packet -> PCM), picked
  by `VoiceBackends`: Steam session -> `SteamVoiceCapture`/`SteamVoiceCodec` (Facepunch SteamUser voice);
  Unity Transport -> `MicrophoneVoiceCapture` (Unity Microphone, resampled to 16 kHz, G.711 mu-law,
  ~16 kB/s per speaker, LAN/MPPM only); batch mode -> `SilentVoiceCapture`; tests/nettest ->
  `ToneVoiceCapture` via `VoiceBackends.CaptureOverride`. Packets carry their codec id. A bought SDK
  (Dissonance) would replace capture + codec + relay.
- `NetworkVoice` (Player prefab): owner -> host by unreliable RPC (sender must be the owner, size <=
  1200 B, known codec), host relays to everyone but the owner (`SendTo.NotOwner`); receivers drop
  stale/duplicate packets by sequence number. Host raises `NetworkVoice.HeardOnHost(voice, level, radio)`
  (level = RMS measured by the sender, one byte) for monster noise (M4.3).
- `VoicePlayback` ("Voice" child at eye height): jitter buffer (`VoiceJitterBuffer`: 120 ms prime, 500 ms
  cap, re-primes on underrun, drops oldest) pulled by a streaming AudioClip on the audio thread; Unity only
  pans (flat custom rolloff), volume = `VoiceMath.DistanceGain` (full within 1.5 m, inverse-distance
  fading to 0 at 25 m) x player voice volume. Owner's own playback disabled.
- `VoiceTransmitter` (owner only): PTT on V (PlayerInputFrame.TalkHeld; R = radio also keys the mic),
  open mic with RMS threshold 0.02 + 0.4 s hang; capture opened lazily once the owner is spawned (remote
  copies must never touch the shared mic). Min packet 20 ms.
- `VoiceSettings` (PlayerPrefs, not in batch mode): mode, others' volume, mute. `VoiceSettingsPanel`
  (scene Network object, shown with a free cursor) edits them. `VoiceHud` (owner): "● TALKING / RADIO",
  why you can't talk, ((•)) over talking players, F1 per-speaker packets/buffer/underruns/gain.
- Tuning: Data/Voice/VoiceConfig.asset. macOS microphone usage text set by BuildScript.

### M4.2 notes (occlusion + radio)
- `VoicePlayback` raycasts ear -> mouth each frame against everything except Player/Loot/Debris/Ignore
  Raycast (walls and floors count); per wall volume x0.55 and a low-pass (AudioLowPassFilter on the Voice
  child) at 900 Hz for one wall, x0.6 per further wall, max 3 walls, smoothed at 8/s. Muffled, not silent.
- Radio: hold R (also keys the mic). `NetworkVoice.RadioHolder` (client id -> has a walkie-talkie)
  decides; unset = `VoiceConfig.EveryoneHasRadio` (true until equipment, M6). The host strips the radio
  flag from anyone without one; receivers play radio packets only if they hold a radio, through the
  speaker's "Radio" child: 2D AudioSource, high-pass 400 Hz + low-pass 3.2 kHz, hiss + slight overdrive
  added on the audio thread (`VoiceStream` processor). The speaker is still heard in person too.
- `VoiceStream` (shared by both playbacks): jitter buffer + streaming clip per AudioSource.
- F1 voice view adds walls / low-pass per speaker and radio samples.

### M4.3 notes (voice as noise)
- Host only: each accepted voice packet's sender-measured level -> `VoiceMath.NoiseLoudness`: 0 at or
  below WhisperLevel (RMS 0.015), linear to ShoutLoudness 0.6 (24 m hearing radius) at ShoutLevel 0.25;
  a radio transmission adds RadioLoudness 0.12 (key click/static) at the speaker. `VoiceNoiseMeter`
  emits the first packet after quiet at once, then at most one event per 0.25 s with the loudest moment.
  `NoiseSystem.Emit(mouth, loudness, NoiseSource.Voice)`; visible in the F1 noise view. Monsters (M5)
  subscribe to NoiseSystem as for footsteps.
- Trust: the level comes from the speaker's client; a modified client could under-report to sneak.
  Acceptable for co-op; the host could decode and measure itself later (mu-law is cheap, Steam needs Steam).

## M4 review (2 parallel reviewers, adversarially verified) — fixed unless noted
No high-severity findings. Fixed:
- Audio: the jitter cushion now covers Unity's streamed-clip read size (EnsureTarget = read + 120 ms;
  otherwise 4096-sample reads at 16 kHz underran every 256 ms); a short utterance below the cushion
  plays once the speaker stops (StartNow); a stopped stream restarts on the next packet and old clips
  are destroyed; push-to-talk always sends while keyed and Steam's buffered tail after release, muting
  drains without sending; Steam reads use a 1200 B buffer and decode buffers hold 0.5 s at 48 kHz.
- Microphone: system default input (null) instead of devices[0]; `MicResampler` is continuous across
  chunks (no dropped sample per packet) with a moving-average low-pass when decimating; exact-zero input
  for 2 s reports "allow microphone access"; no per-packet array allocations.
- Network: `ToListenersRpc` accepts only the host (any client could otherwise invoke it via NGO's proxy
  and speak as someone else or jam their sequence numbers); the host caps 100 packets/s per speaker; a
  remote ragdolled player's voice (and noise) comes from the body, not the root left upstairs; the
  noise meter drops a held-back peak after a pause (a stale shout no longer leaks into a later whisper).
- Settings flush to disk on change / slider release; cached panel GUIStyle.
- Tests: `PlayerInputReader.Override` (input seam for tests/replays) -> holding V sends, R uses the
  radio, release stops; resampler continuity/decimation; jitter target; stale noise peak.
Deferred: per-packet byte[] allocations in NGO RPC params (NativeArray would avoid them); Steam codec
allocates a MemoryStream per decode; out-of-order packets are dropped rather than reordered.
