### 10.1 notes (truck upgrades)
- `TruckUpgradeDefinition` tiers (Data/Company/TruckUpgrades/) in an append-only `TruckUpgradeCatalog`; owned ids live in
  CompanySave.unlocks (bankruptcy clears them); `CompanyNetState.TruckUpgrades` is a bitmask by catalog index.
- Shop "THE TRUCK" section: a tier shows once the one below is owned; the host checks level, tier and money.
- Effects ride on RunTerms (host): cargo capacity x Amount, honk = Amount s (RunNetState.HonkSeconds so the lever prompt
  is right on clients), armor = `RunState.Shelters` (Threat.KillWithinReach and the Blind One skip players in the
  truck's ride zone). Floodlights: `TruckFloodlights` on the truck, every machine, off the building's power.
- Tiers: Bigger Bay x1.35 (L2 $12k), Floodlights (L3 $8k), Tuned Engine 7 s (L4 $10k), Box Truck x1.75 (L5 $30k),
  V8 4 s (L7 $25k), Armored Bay (L9 $40k). Prices assume the 10.9 economy pass.

### 10.2 notes (flatbed trolley)
- EquipmentKind.Flatbed (appended), `flatbed` gear (L3 "better trolley", GDD 13). In a hand slot it sets
  `PlayerCarrier.FlatbedDrag` on every machine: Heavy and Huge items can be dragged short-handed (it doubles as a
  hand trolley). A Huge item drags at CarryConfig.HugeDragSpeedScale (0.55) of the normal drag speed.
- `SharedCarryable.CanBeDraggedUnderCrewed` is now true when ANY carrier has a trolley for the item (it used to ask
  only the first one), so a crew of two with one flatbed can move the piano.
