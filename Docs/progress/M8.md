### 8.1a notes (in-run HUD)
- `HudLayer` (UI): a full-screen, click-through layer under the menus on MenuUi's document; hidden while
  any menu screen shows. HUD components keep their logic and build their elements there on first use
  (no layer in bare test rigs = nothing drawn). Labels are only re-set when their text changes.
- RunHud (top chips: haul vs quota, cargo, window; banners: truck leaving, YOU DIED), InteractionHud
  (crosshair, prompt, throw charge, pockets; keys from the player's bindings, so [LMB]/[RMB] are gone),
  StressScannerHud, VoiceHud (own line + marks over speakers), GhostSpectator (line + threat marks),
  FloatingTextOverlay (rising, fading labels). World marks use RuntimePanelUtils.
- F1 debug readouts stay OnGUI (developer-only).
- Components disabled mid-game hide their elements (OnDisable) so nothing stale stays on screen.

### 8.1b notes (HQ + appraisal screens)
- `ScreenPanel` (UI): a centred, clickable panel on the HUD layer for screens the world opens; its
  contents rebuild only when the screen's state key changes (board seeds + selection, money + stock +
  slots, results + payday), so buttons aren't recreated every frame.
- HqHud (chips), ContractBoardScreen (three job cards; host-only buttons), GearScreens (shop rows with
  Buy, rack slot buttons with stock counts; keys from bindings), AppraisalScreen (item table, crew, stats,
  payday, host's Back to HQ / Next run). Each keeps its open/close flags, Esc and cursor claim.
- No player-facing OnGUI is left; only F1 debug readouts use it.

### 8.2 notes (onboarding)
- `HintDirector` (session object, local): every 0.25 s picks the most pressing unseen tip for this
  moment: ghost; at the HQ (only where a ContractBoard exists) board then van; in a run: truck leaving,
  cracking floor under your feet, a Blind One / Stalker / Collector within 18 m, the run goal (2 s in),
  power off, first pocketed item, first held item (throw), first heavy / shared item in reach, first loot
  in reach. One at a time for 9 s (`HintView`, HUD layer).
- `Hints`: seen flags + "Show tips" in Prefs; Settings has Show tips and Show all tips again. Texts use
  the player's bindings.
- `HowToPlayView` (pause menu): the job, the building, the loot, the dark, and the keys.
- Bug caught by HintTests: the company service lives in every level, so "read the board" showed in the
  mall before its run spawned; HQ tips now need a contract board in the scene.

### 8.3 notes (demo flavour)
- `BuildFlavor.Demo`: a Shareable-style player (universal Mac, Win64, steam_appid 480) stamped "Demo" in
  BuildInfo; `Tools/unity.sh build-demo` makes Game/Builds/MacDemo + WindowsDemo and zips them
  (`Abandoned-<ver>-<commit>-MacDemo.zip`). `Core.Demo.IsDemo` reads the stamp (tests/editor: `Demo.Force`).
- `DemoConfig` (Data/Core/Resources): MaxJobs 5, StoreAppId (0 until the real App ID), StoreUrl.
- The demo keeps its own company save (`company_demo.json`).
- CompanyService.DemoOver (runs >= MaxJobs): no job can be selected; the board says the demo is over and
  opens the end screen. MenuUi shows `DemoEndView` once per arrival at the HQ (stats, Wishlist on Steam
  = the Steam overlay's store page via `SteamBootstrap.OpenStorePage`, else the browser; host: Start a
  new company = `RestartDemo`; Back to the HQ; Quit). ISteamClient gained OpenStoreOverlay.
- The main menu's subtitle says DEMO and the job count.
