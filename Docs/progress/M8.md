### 8.1a notes (in-run HUD)
- `HudLayer` (UI): a full-screen, click-through layer under the menus on MenuUi's document; hidden while
  any menu screen shows. HUD components keep their logic and build their elements there on first use
  (no layer in bare test rigs = nothing drawn). Labels are only re-set when their text changes.
- RunHud (top chips: haul vs quota, cargo, window; banners: truck leaving, YOU DIED), InteractionHud
  (crosshair, prompt, throw charge, pockets; keys from the player's bindings, so [LMB]/[RMB] are gone),
  StressScannerHud, VoiceHud (own line + marks over speakers), GhostSpectator (line + threat marks),
  FloatingTextOverlay (rising, fading labels). World marks use RuntimePanelUtils.
- F1 debug readouts stay OnGUI (developer-only).
- Components disabled mid-game hide their elements (OnDisable) so nothing stale stays on screen.

### 8.1b notes (HQ + appraisal screens)
- `ScreenPanel` (UI): a centred, clickable panel on the HUD layer for screens the world opens; its
  contents rebuild only when the screen's state key changes (board seeds + selection, money + stock +
  slots, results + payday), so buttons aren't recreated every frame.
- HqHud (chips), ContractBoardScreen (three job cards; host-only buttons), GearScreens (shop rows with
  Buy, rack slot buttons with stock counts; keys from bindings), AppraisalScreen (item table, crew, stats,
  payday, host's Back to HQ / Next run). Each keeps its open/close flags, Esc and cursor claim.
- No player-facing OnGUI is left; only F1 debug readouts use it.
