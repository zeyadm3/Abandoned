### M5.2 notes (loot spawning)
- `LootDefinition.SpawnTags` (store kinds = mall zone tags) + `Jackpot`. `LootSpawnPoint` (tag, carry
  class range, jackpot flag). `LootSpawnPlanner` (pure, seeded): shuffles jackpot points and uses 1-2
  (`LootSpawnConfig` JackpotsMin/Max) with jackpot items only; every ordinary point fills with
  FillChance 0.6, picking by Rarity among items whose tags and class fit; every point draws its random
  numbers whether used or not, so one point never shifts another.
- `NetworkLootSpawner` (Networking, scene object): host only, on server start: plans from its seed,
  instantiates from `LootCatalog` (Data/Loot/LootCatalog.asset, written by the prefab generator: runtime
  definition -> prefab map), rolls the value seed before `Spawn()`; clients get NGO spawns. F1 shows
  seed/count/total value. Seed is a field until the run flow sets it (`SetSeed`).
- Mall points (`MallLootPoints`): every other tile in stores, one in three in open areas, one Heavy spot
  per store, jackpot points in the gallery (floor 2), furniture (floor 1) and loading bay. Seed 1:
  88 items on 143 points, ~$313k in the building.
- New items: diamond ring, pearl necklace, smartphone, game console, collector's figure, desktop PC,
  large painting, espresso machine, grandfather clock (Heavy), film projector (Heavy). Spawn tags are
  only written into definitions that have none (tuning in the inspector is kept).
