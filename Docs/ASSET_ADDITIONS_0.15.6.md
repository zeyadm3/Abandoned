# 0.15.6 original prop additions

These are authored static dressing prefabs with three saved LODs, reusable worn PBR finishes,
simple box collision proxies and `Sockets/HighlightAnchor` plus `Sockets/InspectionAnchor`.
There is no Rigidbody on fixed dressing. Shelf stock loses collision when placed inside its support.
Triangle figures below are estimated production budgets, not measured asset counts. All finishes
reuse base color, metallic/smoothness, tangent normal and ambient occlusion maps from the salvage
library. Dust, rubbed edges, scratches, faded paint and packing wear come from those shared finishes.

Every concept prompt below can be used independently. Prefix it with:
“Isometric three-quarter game asset concept, abandoned mall salvage by Solutions Inc. Clearance
Division, original low-poly hard-surface silhouette, realistic worn PBR surfaces, neutral gray
background, full object visible, soft studio light, no people, no watermark.” Concepts are prompts;
the shipped meshes are original code-authored art.
